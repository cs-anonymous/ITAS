# 24TeamA_智能文本标注系统

## 项目介绍

可扩展的多领域智能文本标注与挖掘系统（ITAS），旨在协助研究人员高效准确地进行科学文献中段落和实体的标注，以及自动化提取和挖掘预设定义的关键信息。
- 多领域支持：系统设计将充分考虑到不同研究领域的特殊需求，通过模块化和可配置的标注预设，支持广泛的学科和专业领域，包括但不限于社会科学、生物医学、工程技术等。
- 协助标注：提供一个用户友好的界面和工具集，协助研究人员进行科学文献的段落和实体标注工作。通过预定义的标注规则和模板，以及智能推荐和辅助功能，大幅降低标注工作的难度和时间成本，提高标注数据的准确性和一致性。
- 自动化抽取：利用先进的大语言模型和自然语言处理技术，如GPT系列，实现从标注的文档中自动化提取和挖掘预设定义的关键信息。系统将支持小样本学习，以适应数据稀缺的研究场景，从而提高从大量未标注文本中快速准确提取信息的能力。

通过实现这些目标，ITAS旨在为学术研究和其他领域的专业人士提供一个强大的支持工具，帮助他们在信息海洋中快速定位、提取和利用知识，从而加速科学发现和知识创新的过程。

### Commit格式

提交（commit）的格式形如 **标题：详细描述**，可以省略详细描述，不需要添加时间、人物等元信息，commit本身自动带有，commit规范如下：

1. **提交消息格式**：确保每个提交都有一个清晰、简洁的消息。一般来说，提交消息应该包括一个标题/摘要（不超过50个字符），后跟一个可选的更详细的描述，描述之间应该用空行分开。

2. **使用有意义的消息**：提交消息应该具体且有意义，描述所提交的更改或解决的问题。例如，“修复了导致应用崩溃的内存泄露”。

3. **遵循动词原则**：提交消息的动词应使用现在时，并且是命令式的，比如“添加”、“更新”、“删除”等，表明提交将要完成的动作。

4. **关联任务或问题**：如果提交与任务管理工具中的问题或任务相关联，应在提交消息中提及该任务的编号。例如，`Fix #123: 修复了导航栏链接问题`。

5. **小步提交**：频繁地进行小步提交比偶尔进行大规模提交更好。这样不仅可以减少合并冲突，还可以让其他团队成员更容易理解每次提交的目的。

6. **避免无意义的提交**：尽量避免提交未完成的代码。如果必须这么做（比如要结束工作日），请清楚地在提交消息中标注，例如使用WIP（工作进行中）。

7. **代码审查**：在代码合并到主要分支之前，进行代码审查。这不仅可以确保代码质量，还可以增加团队成员之间的知识共享。
