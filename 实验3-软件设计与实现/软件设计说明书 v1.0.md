# 1. 引言

## 1.1 系统概述

“cÁI思泉涌”是一个基于深度学习算法的诗词对联生成系统，旨在为广大诗词爱好者及文字工作者提供快捷有效的诗词对联生成功能，使用深度学习赋能传统文化，方便用户快速查找现有的高质量的诗词对联或生成属于自己的诗词对联。系统支持根据用户提供的关键词生成或随机生成对联、唐诗或宋词，并支持用户收藏。此外，系统支持用户向管理员反馈使用系统过程中遇到的问题，以便系统不断进行改进。本系统的创作初衷为：提升传统文化的创作活力，扩展深度学习在生活中的应用。

## 1.2 编写目的

该文档的设计是为了让cÁI思泉涌诗词对联自动生成系统的开发人员明确各阶段的任务需求和开发进度，便于开发人员之间相互交流，相互合作，完成开发任务。在保证可完成性的情况下，尽可能详细地约定各个模块的实现细节，记录项目落实过程中的各种方案思路和决策意见。另一方面，在后续的软件测试阶段，测试人员还可参考此文档完成测试任务。

## 1.3 文档范围

该设计文档的使用范围为整个工程开发的全部阶段，包括：背景调研阶段、需求分析阶段、产品设计阶段、系统开发阶段、性能优化阶段、软件测试阶段和最终发布阶段，每个阶段都根据设计文档逐步推进。背景调研阶段确定项目内容，着手设计文档的框架搭建；需求分析和产品设计阶段对系统的最终完成版进行构想并提出可能实现的功能，在后续开发过程中根据实际情况不断进行迭代修改；系统开发阶段按照之前提出的功能设计分模块按步骤有序完成；性能优化阶段按照已有的初级系统，结合设计文档和实际需求对各个功能进行优化；软件测试阶段按照设计文档就曾经提出来并已实现的功能进行系统测试，并提出意见供相关开发人员修改；最终发布阶段完善设计文档，并按照预期时间发布软件。

## 1.4 读者对象

该文档的读者范围为cÁI思泉涌诗词对联自动生成系统团队全体成员（乙方）和课程专家组人员（甲方）。

# 3. 系统总体设计

本节概述了系统的总体设计以及功能模块划分和描述。本系统的用户主要包括：

**游客：**游客在本系统中指未登录的系统使用者。游客可以使用随机生成对联、唐诗、宋词、登录、注册等系统功能。游客注册后拥有用户的权限。游客通过登录成为用户或管理员。

**用户：**用户是本系统的主要使用者。用户可以泛化为游客，因此用户拥有游客的所有权限，可以使用随机生成对联、 唐诗、宋词等功能。用户也可以使用系统中的搜索对联诗词、收藏、问题反馈、先验生成等功能。

**系统管理员：**管理员是本系统的管理者。管理员可以使用查看反馈信息、替换模型、管理用户信息等功能。管理员主要负责对用户进行管理，可以禁用一些恶意破坏系统的用户账号，维护系统稳定。管理员同时也负责收集和回复反馈信息，协助促进系统迭代。

## 3.1 系统架构图

系统整体架构如下图3.1所示。整个项目使用MySQL关系型数据库和ElasticSearch搜索引擎作为数据接入，并使用阿里云服务器作为计算接入。在服务层面，系统主要使用控制器与Django框架进行交互，在控制器中实现基本所有步骤，控制器控制日志子系统，搜索系统，并进行数据采集，通过MQ总线与深度学习网络连接。在深度学习网络方面，在唐诗生成中使用基于Bert的九歌和基于LSTM的PH模型两个模型，在宋词生成中使用基于CVAE的AAAI2018开源模型，在对联生成中使用基于HMM的高Star开源模型。在Vue.js 前端和后端的交接层定义边界业务单元，并分别定义游客边界，用户边界和管理员边界。
